# e-plantShopping

e-plantShopping is a React-based web application developed as part of the Coursera React course final project. The application provides an online plant shopping experience where users can browse plant products, view details, and manage their shopping cart.

This project demonstrates the use of React components, state management, props, and modern front-end development practices.

## Features
- Display a list of plant products
- View plant details
- Add and remove items from the shopping cart
- Responsive and user-friendly interface

## Technologies Used
- React
- JavaScript (ES6)
- HTML
- CSS

This project is created for educational purposes as part of the IBM Developer Skills Network curriculum.
